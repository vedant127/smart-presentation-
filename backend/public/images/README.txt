Cover background image for PPTX generation
===========================================

Place a city skyline or building photo here to use as the cover slide background:

  cover_bg.jpg   (recommended)
  cover_bg.png

Supported locations (checked in order):
  1. backend/public/images/cover_bg.jpg
  2. backend/public/images/cover_bg.png
  3. backend/Library/assets/cover-bg.jpg
  4. backend/Library/assets/cover-bg.png

If no image is found, the cover will use a plain navy blue background.

Recommended: 1920x1080 or 16:9 aspect ratio for best results.
